# Hitop Marketing Common

Read `references/brand-rules.md` before producing any Hitop Realty marketing output. Use `references/test-samples.md` only for examples or dry-run tests.

Apply these priorities:

1. Use only verified facts from the user, the repository, public pages, or clearly cited official sources.
2. Mask or omit personal information before using source material.
3. Separate facts, assumptions, and items needing confirmation.
4. Keep content natural for Korean real-estate customers; avoid keyword stuffing, false urgency, hidden claims, and exaggerated guarantees.
5. Do not publish, upload, schedule, buy ads, call external posting APIs, or change website operation code from this skill.
