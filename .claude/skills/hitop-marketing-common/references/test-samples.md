# 테스트용 공개 샘플 자료

실제 고객정보나 비공개 매물을 쓰지 말고 아래 샘플로 dry run 한다.

## 샘플 매물

- 매물번호: HITOP-SAMPLE-001
- 지역: 파주시 월롱면
- 매물종류: 공장
- 거래유형: 임대
- 대지면적: 1,200㎡
- 건축면적: 420㎡
- 층수: 1층
- 보증금: 확인 필요
- 월세: 확인 필요
- 진입도로: 2차선 도로 인접
- 전력: 확인 필요
- 층고: 확인 필요
- 주요 특징: 차량 진입 가능, 창고 겸용 검토 가능, 파주 북부권 이동 동선
- 공개 가능 메모: 현장 확인 후 용도와 업종 적합성 확인 필요

## 샘플 주제

- 파주 공장 임대 매물을 찾는 사업자가 확인해야 할 것
- 운정 오피스텔 전월세 상담 콘텐츠 기획
- 파주 토지·공장부지 매매 광고 문구
- GA4 `click_phone`, `click_kakao`, `generate_lead` 성과 요약

## 샘플 금지 입력

아래 정보는 테스트에서도 그대로 쓰지 않는다.

- 고객명: 홍길동
- 고객 연락처: 010-1234-5678
- 소유주 연락처: 010-9999-0000
- 내부 메모: 가격 조정 가능, 비공개 협의

마스킹 예: 홍**, 010-****-5678.
